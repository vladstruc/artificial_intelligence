В данном разделе была проведена работа с датасетом онлайн-покупок (вычисление математического ожидания, корреляции, дисперсии, медианы по месяцам) и построена тепловая карта корреляции для числовых величин. Самое большое значение для матожидания и дисперсии по месяцам было в феврале, большое значение медианы - в июне. Тепловая карта корреляции показывает, как величины связаны между собой (синий цвет- сильная отрицательная корреляция, красный цвет - сильная положительная корреляция). Например, между BounceRates и ExitRates сильная положительная корреляция (красный цвет), между ExitRates и ProductRelated - сильная отрицательная корреляция (синий цвет).
