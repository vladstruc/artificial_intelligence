Задача - определить, завершится ли сессия посетителя сайта покупкой. Тип задачи - бинарная классфикация, поскольку таргет предсказывает бинарное значение (Да/Нет).
Таргет - столбец Revenue.
Признаки - остальные столбцы.
Для сравнения моделей выбраны метрики roc_auc и f1, поскольку в обучающей выборке имеется сильный дисбаланс классов (1336 положительных и 7295 отрицательных значений)
По результатам сравнения я бы выбрал модель,реализованную с помощью DecisionTree, поскольку данная модель даёт самые хорошие показатели по метрикам f1 и roc-auc.
Признак переобучения модели я выбирал следующий: если разница между значениями f1  обучающей выборки и f1 тестовой выборки значительна, имеется проблема переобучения модели. В нашем случае ни одна модель не имеет проблем с переобучением.
